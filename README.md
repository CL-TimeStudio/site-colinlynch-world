# site-colinlynch-world

Public website repository for general public-facing pages and supporting static-site content associated with Colin Lynch.

## Repository type

Site repository.

## Purpose

This repository stores public website content and static assets for a general information site. It is intended to be legible to humans, GitHub, and connected tooling.

## Public-safety boundary

This repository should contain public website material only. Do not store private notes, credentials, unpublished intellectual property, internal handoff content, customer data, or secrets here.

## Operating notes

- Keep top-level context files simple and current.
- Use `SITE-MANIFEST.md` for site-level metadata.
- Treat this as a public presentation surface rather than a private source-of-truth repository.
